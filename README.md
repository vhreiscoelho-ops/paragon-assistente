# Assistente do Aquarista · Paragon Fish (beta)

App de navegador instalável (PWA) para acompanhar aquários: diário de parâmetros, ciclagem guiada, alertas com fonte e checador de compatibilidade.

- Sem login, sem servidor, sem cookies e sem analytics: os dados de cada pessoa ficam só no aparelho dela.
- Este repositório contém apenas os arquivos estáticos publicados no GitHub Pages.

Encontrou um problema de segurança? Use **Security → Report a vulnerability** (relato privado).
